# outputs/ 产物说明

运行产物按类型分目录存放。除本文件和 `示例/` 外，`outputs/` 已被 gitignore，不会进入版本库。

| 子目录 | 内容 | 生成方 |
|---|---|---|
| `龙虎榜简报/` | 前一交易日龙虎榜简报 | `morning_flow.py --lhb` |
| `竞价预案/` | 9:25 竞价终局预案 | `morning_flow.py --auction` |
| `收盘报表/` | 收益报表、KPI 评估、告警、健康检查 | `r47_closed_loop.py`、`src.reports`、`src.kpi` |
| `决策日志/` | 当日决策与成交留痕 | `src.decision_log` |
| `扫描发现/` | 项目体检与问题清单 | 维护者 |
| `选股/` | 选股结果、观察池导出 | `src.watchlist`、选股流程 |
| `研究/` | 回测与因子研究结果 | 研究脚本 |

## 示例

`示例/` 下的文件仅用于展示格式，标的、价格、盈亏均为虚构数据，不代表任何真实账户。

## 产物核对

重跑前先确认：

1. 数据日期与交易日历一致；
2. 报表注明数据源、缺失项和口径；
3. sim / real 分账正确；
4. 无法计算时明确写"结论无效"，不要用旧值填充。
